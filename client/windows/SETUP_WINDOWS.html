Installation Steps

Follow each step in order — the entire setup takes about 10 minutes.

1
Install Python
  1. Go to python.org/downloads
  2. Download Python 3.11 or later (the large button at the top)
  3. Run the installer — check "Add Python to PATH" at the bottom of the first screen
  4. Click "Install Now"
  5. Verify: open Command Prompt and type python --version — should show 3.11+
⚠ Critical: You must check "Add Python to PATH" during installation or the app will not be able to find Python. If you already installed Python without this option, reinstall it.
2
Get Schwab API Credentials
  1. Go to developer.schwab.com and sign in with your Schwab account
  2. Click My Apps → Add Application
  3. Fill in the form:
    — App Name: anything (e.g. My Trader)
    — Callback URL: https://127.0.0.1:8182
  4. After approval (usually instant), click your app to see your App Key and App Secret
  5. Save both — you'll enter them in Step 4
ℹ️ Note: Approval is typically instant. If it takes longer, check your email for a confirmation from Schwab.
3
Install the Trader App
  1. Open the windows\ folder inside your downloaded BLEETrader package
  2. Double-click install.bat
  3. A terminal window opens and installs the required Python packages
  4. Wait for "Installation complete!" — usually 1–2 minutes
Tip: If you see an error about pip not being recognized, Python was not added to PATH. Go back to Step 1 and reinstall Python with the PATH option checked.
4
Configure Your Credentials

Open src\.env in Notepad and fill in your values:

SCHWAB_API_KEY=your_app_key_here
SCHWAB_APP_SECRET=your_app_secret_here
SCHWAB_ACCOUNT_NUMBER=12345678          # 8-digit account number
SCHWAB_TOKEN_PASSPHRASE=choose_a_passphrase # anything secure
SCHWAB_CALLBACK_URL=https://127.0.0.1:8182
PORTFOLIO_VALUE=10000.00                   # trading budget in dollars
🔒 Security: Never share your .env file with anyone. It contains credentials that grant full trading access to your Schwab account.
ℹ️ Note: You can also update all these values later in the Settings tab inside the app.
5
Authenticate with Schwab (One-Time Setup)
  1. Double-click windows\auth_schwab.bat
  2. Your browser opens — click "Sign in with Schwab"
  3. Your browser will warn about a certificate — click Advanced → Proceed to 127.0.0.1 (this is expected and safe — the connection is local only)
  4. Log in with your Schwab credentials and complete 2-factor authentication
  5. You'll see a "Authenticated successfully" page
  6. Close the browser tab and press Ctrl+C in the terminal window
🔑 Result: A token file is saved at src\schwab_token.enc — encrypted with your passphrase. Do not delete this file.
6
Start the App
  1. Double-click windows\run.bat (or the desktop shortcut if you created one)
  2. Your browser opens automatically at http://127.0.0.1:5060
  3. Sign in with your BLee Quant Analytics account (the same email you use on bleeanalytics.com)
  4. You're in — start trading!
✅ You're all set! The app runs entirely on your computer — live investment model data is fetched from BLee Quant Analytics, and trades are sent directly to Schwab via their API.
7
Create a Desktop Shortcut (Optional)

Double-click windows\create_shortcut.bat to add a "BLee Quant Pro Trader" shortcut to your desktop for quick access.

Weekly Schwab Re-Authentication
🔄

Schwab tokens expire every 7 days

When the app shows a token error, stop the app, run windows\auth_schwab.bat, complete the Schwab login, then restart with windows\run.bat. This takes about 60 seconds.

Troubleshooting

Common issues and how to fix them quickly.

"Schwab not configured" error
Check that src\.env has your API key, secret, and passphrase filled in correctly.
"No Schwab token found"
Run windows\auth_schwab.bat to authenticate. This step is required before the first launch and after each 7-day expiry.
Browser shows "Proceed" warning during auth
This is expected. Click Advanced → Proceed to 127.0.0.1. The connection is entirely local — no data leaves your computer.
"Access denied" on login
Your BLee Quant subscription must be Pro or Ultimate. Check your status at bleeanalytics.com/subscribe.html.
App won't start — Python not found
Reinstall Python from python.org and make sure to check "Add Python to PATH" during installation.
"pip is not recognized"
Python was not added to PATH. Reinstall Python with the "Add Python to PATH" option checked.

Security Notes

Your data and credentials stay on your computer.

🔒
Credentials Stay Local Never share your .env or schwab_token.enc files. They contain keys that grant trading access to your account.
🔐
Encrypted Token The Schwab token is encrypted with your passphrase. Keep the passphrase somewhere safe — you'll need it if you reinstall.
🖥️
Runs On Your PC The app runs entirely locally. No trade data or account info is sent to BLee servers.
📡
Read-Only Data Feed Investment model allocations are fetched read-only from bleeanalytics.com. No personal data is transmitted.
